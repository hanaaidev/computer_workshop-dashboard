## English

A dashboard-style portfolio of ten hands-on IT projects from the Computer Workshop course, covering system information, troubleshooting, networking, virtualization (Linux VM), a portable toolkit, performance analysis, storage management, security review, batch scripting and a final IT-support simulation. Each project has its own report with the goal, tools, execution steps, screenshots, analysis, problems and solutions, and lessons learned.

Built with plain HTML, CSS and JavaScript — no frameworks, no build step. The site is available in Persian (RTL) and English (LTR); use the language button at the top of any page.

### Structure
```
index.html            Persian dashboard (home)
projects/             Persian project reports
en/index.html         English dashboard
en/projects/          English project reports
css/style.css         Shared dark theme, responsive layout, print rules
css/en.css            LTR overrides for the English pages
js/dashboard.js       Basic interactions
assets/screenshots/   Screenshots used by both language versions
```

### Run locally
Open `index.html` in Chrome or Edge. To save a report as PDF, use the **Print / Save PDF** button and choose *Save as PDF*.

## فارسی

پورتفولیوی داشبوردی ده پروژه‌ی عملی IT از درس کارگاه کامپیوتر؛ شامل مشخصات سیستم، عیب‌یابی، شبکه، ماشین مجازی لینوکس، جعبه‌ابزار قابل‌حمل، تحلیل عملکرد، مدیریت فضا، بررسی امنیت، اسکریپت Batch و پروژه‌ی نهایی پشتیبانی IT. هر پروژه گزارش جداگانه‌ای با هدف، ابزارها، مراحل اجرا، تصاویر، تحلیل، مشکلات و راه‌حل‌ها و آموخته‌ها دارد.

با HTML، CSS و JavaScript ساده ساخته شده و دو زبانه است (فارسی و انگلیسی)؛ از دکمه‌ی زبان بالای هر صفحه استفاده کنید.

### اجرا
فایل `index.html` را با Chrome یا Edge باز کنید. برای خروجی PDF از دکمه‌ی «چاپ / ذخیره PDF» استفاده کنید.
